# Titanic and Iris Datasets Analysis

## Task Description
Loading and performing initial analysis of two datasets: Titanic and Iris. Creating visualizations for data exploration.

## Datasets

### 1. Titanic
- **Source**: Kaggle Competition
- **Description**: Passenger data from the Titanic
- **Goal**: Survival analysis
- **Columns**: PassengerId, Survived, Pclass, Name, Sex, Age, SibSp, Parch, Ticket, Fare, Cabin, Embarked

### 2. Iris
- **Source**: Kaggle (uciml/iris)
- **Description**: Iris flower measurements
- **Goal**: Species classification
- **Columns**: Id, SepalLengthCm, SepalWidthCm, PetalLengthCm, PetalWidthCm, Species

## Visualizations

### Titanic: Age Distribution
Histogram showing the age distribution of passengers. The red line indicates the mean age.

### Iris: Petal Length vs Petal Width
Scatter plot showing the relationship between petal length and petal width for three iris species.

## Libraries Used
- pandas - data loading and processing
- matplotlib - visualization
- seaborn - visualization
- numpy - numerical operations
- kagglehub - dataset downloading

## Result
Datasets successfully loaded, visualizations created for both datasets.
